# Statistical Charting and Graphical Presentation System

## Project Overview

The Statistical Charting and Graphical Presentation System is a Python desktop application developed to help users enter, import, analyse, and present statistical data through graphical charts.

## Features

- Manual entry of statistical data
- Import data from CSV files
- Load sample data
- Preview imported data
- Generate bar charts, pie charts, line graphs, histograms, and scatter plots
- Save charts as PNG images or PDF documents
- Validate inputs and report errors

## Technologies Used

- Python 3.12
- Tkinter for the graphical user interface
- Pandas for data handling
- Matplotlib for chart generation

## Installation and Execution

1. Install Python 3.12.
2. Install the required libraries:

   ```bash
   py -3.12 -m pip install pandas matplotlib
   ```

3. Run the application from the project directory:

   ```bash
   py -3.12 statistical_charting_system.py
   ```

## Project Purpose

This project demonstrates the application of Python programming, graphical user interface design, data processing, and statistical data visualization.
